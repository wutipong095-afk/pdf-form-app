# ใบเสนอราคา (ผู้ขาย)

คู่กับ [SUPPORT.md](SUPPORT.md) · [LICENSE_REGISTRY.md](LICENSE_REGISTRY.md) · [LICENSE_EMAIL.md](LICENSE_EMAIL.md)

## ใช้เมื่อไร

โรงเรียนและหน่วยงานราชการซื้อด้วย **งบประมาณ** ไม่ใช่เงินส่วนตัว
เจ้าหน้าที่พัสดุต้องมีใบเสนอราคาไปตั้งเรื่องขออนุมัติก่อน ถึงจะโอนเงินได้
ถ้าตอบไปว่า "โอนมาแล้วส่งรหัสเครื่อง" อย่างเดียว ดีลกลุ่มนี้จะค้างทุกราย

ลูกค้ารายบุคคลที่จ่ายเงินตัวเองไม่ต้องใช้ — สแกนคิวอาร์จบเลย

## ลำดับเอกสาร

```
โรงเรียนขอใบเสนอราคา → ออกใบเสนอราคา → โรงเรียนตั้งเรื่อง/อนุมัติ
  → โอนเงิน → ออกใบเสร็จรับเงิน → ออกคีย์ → จดทะเบียนคีย์
```

ระหว่างรออนุมัติอาจกินเวลาหลายสัปดาห์ อย่าเพิ่งออกคีย์ให้ก่อน

## เตรียมครั้งเดียว ใช้ได้ตลอด

ก่อนออกใบแรก ต้องตัดสินใจสองอย่างและใส่ให้เหมือนกันทุกใบ:

- **ชื่อและที่อยู่ผู้เสนอราคา** จะใช้ชื่อบุคคลหรือชื่อกิจการ
- **เลขประจำตัวผู้เสียภาษี** และจะคิด VAT หรือไม่ —
  ขึ้นกับว่าจดทะเบียนอะไรไว้ ปรึกษาผู้ทำบัญชีก่อนออกใบจริง
  เอกสารนี้เว้นช่องไว้เฉย ๆ ไม่ได้แนะนำว่าควรจดหรือไม่จด

หน่วยงานราชการมักขอ **สำเนาบัตรประชาชนหรือหนังสือรับรอง** แนบกับใบเสนอราคาด้วย
เตรียมไฟล์ไว้ล่วงหน้าจะได้ไม่ต้องหาตอนลูกค้าเร่ง

## เทมเพลต

เลขที่ใบเสนอราคาใช้รูปแบบ `QT-YYYYMM-NN` เช่น `QT-202608-01`
แล้วจดเลขนี้ลงคอลัมน์ `paid_ref` หรือ `note` ใน [ทะเบียนคีย์](LICENSE_REGISTRY.md)

```
                          ใบเสนอราคา
                          QUOTATION

ผู้เสนอราคา
  {ชื่อผู้ขาย / ชื่อกิจการ}
  {ที่อยู่}
  เลขประจำตัวผู้เสียภาษี: {ถ้ามี}
  อีเมล formdd@xambrain.com

เลขที่        {QT-YYYYMM-NN}
วันที่         {วว/ดด/ปปปป}
ยืนราคาถึง    {วว/ดด/ปปปป}   (แนะนำ 30 วัน)

เรียน
  {ชื่อโรงเรียน / หน่วยงาน}
  {ที่อยู่}

รายการ
--------------------------------------------------------------------
 ลำดับ  รายการ                              จำนวน  ราคา/หน่วย   รวม
--------------------------------------------------------------------
   1    โปรแกรม FormDD                       {N}      {ราคา}.00   {รวม}
        ไลเซนต์ผูกเครื่อง อายุ {1/3/5/10} ปี
        (1 ไลเซนต์ = 1 เครื่อง · ราคาเต็มตามหน้าเว็บ)
--------------------------------------------------------------------
                                       ส่วนลด {X}%   {ส่วนลด}
                                       รวมเป็นเงิน   {สุทธิ}
--------------------------------------------------------------------
  ({จำนวนเงินเป็นตัวอักษร})

เงื่อนไข
  - ชำระเงินเต็มจำนวนก่อนส่งมอบไลเซนต์
  - ชำระผ่าน Thai QR Payment / พร้อมเพย์ ชื่อร้าน แชมเบรน
    หรือโอนตามรายละเอียดที่แจ้งเพิ่มเติม
  - ส่งมอบคีย์ทางอีเมลภายใน 1 วันทำการหลังได้รับชำระเงิน
    และได้รับรหัสเครื่อง 16 ตัวจากเครื่องที่จะใช้
  - ราคานี้ไม่รวมค่าติดตั้งนอกสถานที่
  - โปรแกรมทำงานออฟไลน์ ไม่มีค่าบริการรายเดือน

                                        ผู้เสนอราคา

                                   ..............................
                                        ({ชื่อผู้ขาย})
                                        {วว/ดด/ปปปป}
```

## ส่วนลดปริมาณ

คิดจากราคาเต็มของแถวที่เลือก ตาม [SALES_LICENSE_PLAN.md](SALES_LICENSE_PLAN.md)
(1 ปี 149 · 3 ปี 350 · 5 ปี 500 · 10 ปี 1,000 บาท/เครื่อง)
ถ้าโรงเรียนไม่ระบุอายุ ให้เสนอ **5 ปี 500 บาท**
ใส่เป็นบรรทัดส่วนลดในใบเสนอราคา อย่าไปลดราคาต่อหน่วย —
พัสดุจะเทียบราคากับใบอื่นแล้วสงสัยว่าทำไมไม่ตรงกับหน้าเว็บ

## เก็บไฟล์ไว้ที่ไหน

ใบเสนอราคาและใบเสร็จมีชื่อหน่วยงานและข้อมูลติดต่อ **ห้าม commit**
เก็บใน `sales/` ซึ่งอยู่ใน `.gitignore` แล้ว หรือนอกเรปไปเลย
