# ภาษาที่ใช้กรอก PDF ใน FormDD

ข้อมูลจากการทดสอบวันที่ 11 กันยายน 2569  
ฟอนต์ที่ทดสอบ: TH SarabunPSK

## ภาษาที่ตัวอย่างทดสอบแสดงผลถูกต้อง

ไทย, อังกฤษ, ฝรั่งเศส, เยอรมัน, สเปน, โปรตุเกส, อิตาลี, ดัตช์, สวีเดน, เดนมาร์ก, นอร์เวย์, ฟินแลนด์, ตุรกี, เวียดนาม, อินโดนีเซีย, มลายู และฟิลิปิโน

ผลนี้มาจากการสร้าง PDF และตรวจข้อความตัวอย่าง ไม่ใช่การรับรองทุกคำหรือทุกตัวอักษรของแต่ละภาษา

## ภาษาที่ยังไม่รองรับครบ

| ภาษา | ผลที่พบ |
|---|---|
| โปแลนด์ และเช็ก | ตัวอักษรพิเศษบางตัวกลายเป็นช่องสี่เหลี่ยม |
| รัสเซีย กรีก ลาว เขมร พม่า จีน ญี่ปุ่น เกาหลี อาหรับ ฮีบรู และฮินดี | ตัวอักษรในชุดทดสอบไม่ครบในฟอนต์ จึงแสดงเป็นช่องสี่เหลี่ยม |

ยังไม่แนะนำให้ใช้ FormDD รุ่นปัจจุบันกรอกข้อความภาษาเหล่านี้สำหรับเอกสารที่จะส่งใช้งานจริง

## ข้อควรระวัง

- ข้อความที่คัดลอกจากบางแหล่งอาจใช้เครื่องหมายกำกับเสียงแยกจากตัวอักษร ซึ่งบางชุดแสดงผลผิดเพี้ยนได้ แม้เป็นภาษาที่ตัวอย่างทดสอบผ่าน
- ผลการแสดงข้อความบนหน้าจออาจต่างจาก PDF ที่บันทึก ต้องตรวจไฟล์ PDF ทุกครั้ง
- หากเปลี่ยนฟอนต์ ผลการรองรับภาษาอาจเปลี่ยนตามไปด้วย
- เมนูของแอปรองรับภาษาไทยและภาษาอังกฤษ แยกจากภาษาที่ใช้กรอกข้อความลง PDF

## ตรวจไฟล์ก่อนใช้งาน

1. กรอกข้อความและกดบันทึก PDF
2. เปิดไฟล์ที่บันทึกแล้ว ตรวจว่าตัวอักษรครบ ไม่มีช่องสี่เหลี่ยมหรือข้อความหาย
3. ตรวจสระ วรรณยุกต์ เครื่องหมายกำกับเสียง และลำดับข้อความ
4. ตรวจว่าข้อความไม่ทับกันหรือเกินขอบช่อง โดยเฉพาะชื่อบุคคลและข้อความยาว

**สำหรับงานสำคัญ ควรตรวจ PDF ที่บันทึกแล้วก่อนพิมพ์หรือส่งต่อเสมอ**
