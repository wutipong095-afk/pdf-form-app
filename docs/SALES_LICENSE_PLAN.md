# แผนขายและไลเซนต์ FormDD

อัปเดต: 2026-08-13  
ใช้คู่กับ [BACKLOG.md](BACKLOG.md) และ [ROADMAP.md](../ROADMAP.md)

เอกสารนี้ล็อกทิศทางจากบทสนทนาเรื่องราคาต่างประเทศ + โมเดลทดลองชุดเดียว  
**ยังไม่ลงมือในโค้ดครบ** — ใช้เป็นแผนแก้ทีละเฟส

## เป้าหมาย

ผู้ใช้ไทยและต่างประเทศใช้ **ตัวติดตั้งชุดเดียวกัน**

```text
ดาวน์โหลด Setup → ติดตั้ง → ทดลองฟอร์มตัวอย่าง
    → ซื้อรายเครื่อง → Activate → ใช้ PDF ของตัวเอง
ไม่ต้องติดตั้งใหม่ ไม่มีตัว Trial / Full แยกไฟล์
```

ต่างกันแค่ราคา สกุลเงิน และช่องทางจ่ายเงิน

## การตัดสินใจที่ล็อกแล้ว

| หัวข้อ | คำตัดสิน |
|--------|----------|
| ไฟล์โปรแกรม | Setup ชุดเดียวทั้งโลก ไม่แยก trial.exe / full.exe |
| โหมดทดลอง | ใช้ได้เฉพาะฟอร์มตัวอย่างทางการ (ตรวจ hash) |
| หลัง Activate | โปรแกรมเดิมปลดล็อก ไม่โหลดชุดใหม่ |
| หน่วยขาย | รายเครื่อง (1 คีย์ = 1 `machine_id`) |
| แพ็กชื่อ Team / School | **ไม่ทำ** — องค์กรซื้อหลายเครื่องแล้วได้ส่วนลดปริมาณ |
| Site license / floating | **ไม่ทำ** ในระยะนี้ |
| สมัครสมาชิกรายเดือน | **ไม่ทำ** — prepaid ตามอายุในคีย์ |
| เติมเงินรายพิมพ์ | **ไม่ทำ** (C3) |
| ออกคีย์ | คีย์ผูก `machine_id` 16 hex ตาม `license_core.py` |
| ตรวจออนไลน์ตอนเปิดแอป | **ไม่บังคับ** — activate ครั้งเดียว แล้วออฟไลน์ได้ |

### ราคา (ยังไม่ใส่ในแอป — ใส่เพจขาย / คู่มือ)

**ไทย (ช่องทางท้องถิ่น)**

- เปิดตัว ~490 บาท / เครื่อง
- อายุคีย์ ~5 ปี (`DEFAULT_SUPPORT_DAYS = 1825`)

**ต่างประเทศ (USD)**

- Personal 1 เครื่อง: **US$69 / 10 ปี** (US, EU, AU, CA, UK)
- ภูมิภาค PPP (ASEAN นอกช่องทางไทย, Latin America): **US$49 / 10 ปี**
- ไม่ขายต่ำกว่า ~US$49 ทั้งก้อนสำหรับไลเซนต์ยาว
- ไม่ตั้ง US$5–12 เป็นราคาหลัก
- ไม่มี SKU รายปีตอนเปิดตัว (ถ้ามีทีหลัง ให้เป็น prepaid ไม่ auto-renew และเป็นตัวเทียบราคาเท่านั้น)

**ส่วนลดปริมาณ** (คิดจากราคาเต็มของลูกค้ารายนั้น)

| จำนวนเครื่อง | ส่วนลด | $69 → | $49 → |
|---|---|---|---|
| 1 | — | $69 | $49 |
| 3–4 | 10% | $62 | $44 |
| 5–9 | 20% | $55 | $39 |
| 10–24 | 30% | $48 | $34 |
| 25+ | 40% แล้ว quote | จาก $41 | จาก $29 |

พื้นต่อเครื่องไม่ต่ำกว่าประมาณ **US$29**

โรงเรียน/องค์กรใช้ตารางเดียวกัน ไม่มีแพ็กที่แพงกว่าบุคคล

**อายุคีย์ในไฟล์ไลเซนต์**

รูปแบบคีย์มีวันหมดอายุวันเดียว (`PFM2.{mid}.{YYYYMMDD}.{sig}`)

- ไทย: `--days 1825` (~5 ปี)
- ต่างประเทศ: `--days 3650` (~10 ปี)

แอปชุดเดียว อายุอยู่ในคีย์ที่ออกให้

**ซัพพอร์ต / ย้ายเครื่อง** (A6 — ต้องเขียนบนเพจขาย)

- ย้ายเครื่องเมื่อเครื่องเก่าเลิกใช้
- โควตารอบแรก: **2 ครั้งต่อใบต่อปี**
- เฟสแรกทำมือ (ออกคีย์ใหม่ให้รหัสเครื่องใหม่)
- สำรองข้อมูลไม่รวม `machine_id` / `license.json` — คงตาม [BACKUP.md](BACKUP.md)

**ข้อความขายต่างประเทศ (แนะนำ)**

> PDF Form Automation. No subscription. From $49 for 10 years.

หน้า US/EU โชว์ **$69 for 10 years** เป็นหลัก  
อย่าเทียบฟีเจอร์กับ Acrobat / Foxit บนหน้าขาย  
อย่าโชว์ “$6.90 / ปี” เป็นตัวใหญ่

## สถานะตอนนี้ vs เป้า

| จุด | ตอนนี้ | เป้า |
|-----|--------|------|
| ตัวติดตั้ง | ชุดเดียว ปลดล็อกด้วยคีย์ | คงไว้ |
| ทดลอง | สร้าง PDF ได้แค่ `demo-form.pdf` (hash) | **เฟส 1 ทำแล้ว** — 3 ใบ + hash |
| อัปโหลดไม่มีคีย์ | อัปโหลดได้ แต่สร้าง PDF ไม่ได้ (402) | **เฟส 1 ทำแล้ว** — ห้ามอัปโหลด (402) |
| คลังเอกสารไม่มีคีย์ | ยังเลือกโฟลเดอร์นอกได้ | **เฟส 1 ทำแล้ว** — ล็อกจนกว่าจะมีคีย์ |
| ออกคีย์ | ผู้ขายรัน `scripts/gen_license.py` จากรหัสที่ลูกค้าส่งมา | **เฟส 2** อีเมลมือ + เทมเพลต · หน้า Activate เป็นเฟส 3 |
| เว็บ | สอนใช้ + ทดลองในเบราว์เซอร์ | **เฟส 2 ทำแล้ว** — ดาวน์โหลด + ราคาไทย/USD คนละหน้า |
| ราคาในเอกสารโปรเจกต์ | ไทย ~490 บาท / 5 ปี | ตารางต่างประเทศในแผนนี้ + หน้า `pricing.en.html` |

`formpacks/v1/` เป็นเทมเพลตจุดสำหรับฟอร์มโรงเรียน **ไม่ใช่** แพ็กทดลอง — อย่าผสมกับ allowlist โหมดฟรี

## เฟสงาน

ทำตามลำดับ อย่าข้ามเฟส 1 ถ้าจะให้คนดาวน์โหลดเองแล้วเข้าใจโหมดทดลอง

### เฟส 1 — ล็อกโหมดทดลองในแอป (ต้องทำก่อนขาย)

ปิดช่องที่คนเข้าใจว่าโปรแกรมพัง หรือใช้ของจริงโดยไม่จ่าย

**1.1 แพ็กฟอร์มทดลอง (A3 / CP5 บางส่วน)**

- ขยาย allowlist จากชื่อเดียว (`demo-form.pdf`) เป็นชุดไฟล์ทางการ + hash
- ตัวอย่างไทย: ใบลา / ใบเบิก ตามที่มีบนเว็บแล้วได้
- ตัวอย่างสากล: อย่างน้อย 1 ใบภาษาอังกฤษ (leave / request)
- ตรวจแบบเดียวกับ `is_canonical_demo_pdf()` — กันเปลี่ยนชื่อไฟล์แล้วใช้เอกสารอื่น
- จุดแก้หลัก: `license_core.py` (`can_fill_document`), โฟลเดอร์ `demo/`, seed ตอนเปิดครั้งแรก

**1.2 ล็อกโหมดฟรี (A4)**

ไม่มีไลเซนต์แล้ว:

- `POST /api/upload` คืน 402 + ข้อความชัด
- เปิดเอกสารจากคลังที่ไม่ใช่ไฟล์ในแพ็กทดลอง ไม่ได้
- UI ซ่อน/ปิดปุ่มอัปโหลดและปุ่มคลัง (B2)

จุดแก้หลัก: `app.py`, `frontend/src/docs.ts`, `frontend/src/license.ts`, `locales/th.json`, `locales/en.json`

**1.3 ข้อความทดลองชัด (B2)**

- แถบไลเซนต์บอกว่าทดลองได้เฉพาะฟอร์มตัวอย่าง
- ปุ่มคัดลอกรหัสเครื่อง (ลดส่งรหัสผิด)
- ลิงก์ไปหน้าซื้อ / Activate (ใส่ได้หลังมี URL จริง)

**ผ่านเมื่อ**

- ไม่มีคีย์: ใช้ฟอร์มตัวอย่างได้ครบ และอัปโหลด PDF นอกไม่ได้
- มีคีย์: อัปโหลดและคลังใช้ได้ตามเดิม
- เปลี่ยนเนื้อไฟล์ตัวอย่างแล้วสร้าง PDF ไม่ได้

### เฟส 2 — นโยบาย + หน้าเว็บดาวน์โหลด (ทำแล้วใน `website/` + docs/SUPPORT.md)

ยังไม่ต้องมีร้านอัตโนมัติ ใช้ได้กับโรงเรียนไทยและออเดอร์ต่างประเทศจำนวนน้อย

**2.1 นโยบายซัพพอร์ต (A6)**

เขียนสั้นในคู่มือ/เพจ:

- อายุคีย์ไทย 5 ปี / ต่างประเทศ 10 ปี
- ย้ายเครื่อง 2 ครั้ง/ปี
- ช่องทางออกคีย์ (อีเมล ชั่วคราว → หน้า Activate เฟส 4)

**2.2 เว็บ `website/`**

- หน้าแรก: ปุ่มดาวน์โหลด Setup (ชุดเดียว) + ทดลองบนเว็บที่มีอยู่
- หน้า Pricing: ตารางรายเครื่อง + ส่วนลดปริมาณ + ราคาภูมิภาค
- ภาษา: ไทย / อังกฤษ คนละหน้าหรือสลับภาษา — ราคาไม่ปน 490 บาท กับ $69 โดยไม่บอกช่องทาง
- คู่มือสั้น: ติดตั้ง → ทดลอง → คัดลอกรหัสเครื่อง → ได้คีย์ → วางในแอป

**2.3 ออกคีย์มือ (ช่องทางชั่วคราว)**

คง `scripts/gen_license.py`  
อีเมลตอบรับต้องมีเทมเพลต: ขอรหัส 16 ตัว, ส่งคีย์กลับ, สอนวางในแถบไลเซนต์  
บนเว็บอย่าสัญญา instant license จนกว่าเฟส 4 จะเสร็จ

**ผ่านเมื่อ**

- คนโหลด Setup จากเว็บแล้วทดลองได้โดยไม่ถามว่าตัวไหนคือตัวจริง
- ผู้ขายออกคีย์จากรหัสเครื่องได้ทั้งไทย (5 ปี) และต่างประเทศ (10 ปี)

### เฟส 3 — หน้า Activate ให้ลูกค้าผูกเครื่องเอง

เป้าขั้นต่ำก่อนขายต่างประเทศเป็นช่องทางหลัก

```text
จ่ายเงิน (หรือได้สิทธิ์จากผู้ขาย)
    → ลิงก์ Activate
        → วาง Machine ID
            → ได้คีย์ทันที
                → วางในแอป ใช้ออฟไลน์ต่อ
```

กติกา:

- จ่าย/ออกสิทธิ์ได้ก่อนติดตั้ง ไม่ต้องมีรหัสเครื่องตอนcheckout
- 1 ออเดอร์ = N ที่นั่ง ผูกทีละเครื่องจนครบ
- Private key อยู่เฉพาะเซิร์ฟเวอร์ผู้ขาย ไม่ลง Setup
- ตรวจออนไลน์เฉพาะตอนออกคีย์
- มี log: ออเดอร์, machine_id, วันหมดอายุ — **ห้าม log คีย์เต็ม**
- ย้ายเครื่อง: เพจ “Replace this computer” นับโควตา ไม่ให้อีเมลหาผู้ขายทุกครั้งระยะยาว

อย่ารวมระบบนีเข้าแอปลูกค้าแบบให้แอปถือ private key

**ผ่านเมื่อ**

- ลูกค้าไม่ต้องส่งรหัสเครื่องมาทางอีเมลเป็นปกติ
- ซื้อ 10 เครื่องแล้ว activate ทีละเครื่องได้จนครบโควตา

### เฟส 4 — ชำระเงิน (หลังเฟส 3)

- ไทย: โอน/พร้อมเพย์ ตามช่องทางที่มี + ออกสิทธิ์ในระบบ Activate
- ต่างประเทศ: Paddle / Lemon Squeezy / Stripe แล้วโยง webhook เข้าโควตาที่นั่ง
- Checkout รอบแรกขาย **1 เครื่อง** ให้จบ
- 3 / 5 / 10 เครื่อง: ปุ่มจำนวน หรือฟอร์ม “Buying for a team?” จนกว่าร้านปริมาณจะคุ้มสร้าง

อย่ารอร้านปริมาณครบก่อนเปิดขายบุคคล

- GitHub Release สร้าง**ทุกครั้ง**เป็นสำเนา (`FormDD-Setup-x.y.z.exe` + `SHA256SUMS.txt`) — ไม่ใช่โฮสต์หลัก

  **ห้าม**วาง private key, `gen_license.py`, `.env`, ฐานข้อมูลลูกค้า
- เฟส 3 Activate ออนไลน์: แยก `api.formdd.xambrain.com` (หรือ `/api` ผ่าน reverse proxy) — คีย์อยู่ใน secret ของ backend เท่านั้น

## ความเสี่ยงที่ต้องรับ

- `machine_id` เป็นไฟล์ UUID ใน AppData ไม่ใช่ซีเรียลฮาร์ดแวร์ — คนคัดลอกโฟลเดอร์ data ได้ เฟสแรกใช้กติกา + ย้ายเครื่องแบบมีโควตา ไม่ทำ TPM ในรอบนี้
- เฟส 3 ทำให้ private key อยู่บน VPS — ต้องล็อกให้เรียกออกคีย์ได้เฉพาะออเดอร์ที่จ่ายแล้ว
- ราคาไทยถูกกว่าอาเซ็น USD มาก — แยกสโตร์ ห้ามโชว์สองราคาบนหน้าเดียวกันโดยไม่บอกช่องทาง
