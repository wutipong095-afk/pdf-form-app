### ราคา (ยังไม่ใส่ในแอป — ใส่เพจขาย / คู่มือ)

**ไทย (ช่องทางท้องถิ่น) — เลือกอายุคีย์ต่อเครื่อง**

ราคาเป็น prepaid ก้อนเดียว ไม่คิดรายเดือน ไม่ต่ออัตโนมัติ  
แอปชุดเดียว อายุอยู่ในคีย์ที่ออกให้ (`--term`)

| อายุคีย์ | ราคา / เครื่อง | `--term` | `--days` | เฉลี่ยต่อปี (อย่าโชว์เป็นตัวใหญ่บนเว็บ) |
|---|---|---|---|---|
| 1 ปี | **149 บาท** | 1 | 365 | ~149 |
| 3 ปี | **350 บาท** | 3 | 1095 | ~117 |
| 5 ปี | **500 บาท** | 5 | 1825 | 100 |
| 10 ปี | **1,000 บาท** | 10 | 3650 | 100 |

- หน่วยยังเป็น **1 ที่นั่ง = 1 เครื่อง** — ซื้อกี่เครื่องคูณแถวนั้น
- โรงเรียน/ใบเสนอราคา **แนะนำแถว 5 ปี** เป็นค่าเริ่มต้น ถ้าลูกค้าไม่ระบุอายุ
- แถว 1 ปีสำหรับทดลองจ่ายเงินจริง ไม่แถมเครื่องที่สอง
- อย่าโชว์ “12 บาท/เดือน” หรือเทียบรายเดือนบนหน้าขาย
- ออกคีย์ด้วย `--term {1,3,5,10}` ตามแถวที่จ่าย — สคริปต์ไม่มีค่าเริ่มต้น 5 ปี ต้องระบุอายุทุกครั้ง · `--days` ไว้ตอนย้ายเครื่องที่เหลือวัน

**ต่างประเทศ (หน้าอังกฤษ — จ่ายครั้งเดียว ไม่ขายว่าถูกกว่า Adobe)**

จุดขายคือเอา PDF แบบฟอร์มที่มีอยู่แล้ว → ปักตำแหน่งครั้งเดียว → กรอกซ้ำได้เรื่อย ๆ → ข้อมูลอยู่ในเครื่อง  
อย่าเทียบฟีเจอร์กับ Acrobat / Foxit และ**ห้ามบอกหรือเทียบราคาบาท**

| แพ็กเกจ | ราคาแนะนำ | ความหมาย |
|---|---|---|
| Free Trial | US$0 | ทดลองแอปจริงกับฟอร์มตัวอย่าง |
| Personal | **US$49** | ราคาหลัก · 1 เครื่อง · จ่ายครั้งเดียว |
| School / Small Team | US$99–149 | 5 เครื่อง US$99 · 10 เครื่อง US$149 |
| Organization | จาก US$249 | หลายเครื่อง — อีเมลจำนวนมา |

ข้อความราคาหลัก:

> US$49 one-time payment — no subscription

- ไม่เขียน “$49 / 10 years” และไม่โชว์ราคาต่อปี
- หน้าเว็บสัญญาแค่ **อัปเดตตราบที่คีย์ยังใช้ได้** (วันหมดอายุบนแถบไลเซนต์) เพราะ `latest.json` ยังชุดเดียวทั้งโลก ตัดฟีเจอร์ที่ปีที่ 5 ไม่ได้
- เป้าในอนาคต: แยกสิทธิ์อัปเดต 5 ปี เมื่อฟีดอัปเดตแยกได้ — อย่าโฆษณาเส้นตัดนี้จนกว่าจะทำได้
- แอปชุดเดียวทุกแพ็ก — ซื้อที่นั่ง ไม่ซื้อฟีเจอร์พิเศษ
- คีย์ยังผูก 1 เครื่อง; แพ็กทีมคือจำนวนที่นั่งในออเดอร์เดียวกัน

ช่วงนี้คีย์ต่างประเทศออก `--term 10` — หน้าเว็บชี้ไปที่วันหมดอายุในแอป ไม่พูดตัวเลข 10 ปี และไม่สัญญาตัดอัปเดตที่ 5 ปี

**ส่วนลดปริมาณ (ใช้ใบเสนอราคาไทยเท่านั้น — ไม่วางบนหน้าอังกฤษ)**

คิดจากราคาเต็มของแถวบาทที่ลูกค้าเลือก ไม่ลดราคาต่อหน่วยในใบ

| จำนวนเครื่อง | ส่วนลด |
|---|---|
| 1 | — |
| 3–4 | 10% |
| 5–9 | 20% |
| 10–24 | 30% |
| 25+ | 40% แล้ว quote |

ตัวอย่าง: 5 ปี 500 บาท × 5 เครื่อง ลด 20% = 2,000 บาท

โรงเรียน/องค์กรไทยใช้ตารางเดียวกัน ไม่มีแพ็กที่แพงกว่าบุคคล

**บัญชีกับที่นั่ง**

- อีเมลเป็นบัญชีสำหรับติดต่อ ดูออเดอร์ ขอย้ายเครื่อง
- ที่นั่งคือไลเซนต์หนึ่งใบ ผูกหนึ่ง `machine_id`
- โรงเรียนใช้อีเมลพัสดุอีเมลเดียวซื้อหลายที่นั่งได้
- ย้ายเครื่อง = ปลดที่นั่งเดิม ผูกเครื่องใหม่ (โควตา 2 ครั้งต่อใบต่อปี) ไม่ใช่ได้เครื่องที่สองใช้พร้อมกัน

**อายุคีย์ในไฟล์ไลเซนต์**

รูปแบบคีย์มีวันหมดอายุวันเดียว (`PFM2.{mid}.{YYYYMMDD}.{sig}`)

- ไทย: `--term 1` / `3` / `5` / `10` (365 / 1095 / 1825 / 3650 วัน)
- ต่างประเทศ: `--term 10` (ภายใน — หน้าเว็บไม่โฆษณา 10 ปี และไม่สัญญาตัดอัปเดตที่ 5 ปี; อัปเดตตราบที่คีย์ยังใช้ได้)

แอปชุดเดียว อายุอยู่ในคีย์ที่ออกให้ — อย่าใส่ราคาสี่แถวลงในตัวแอป

**ซัพพอร์ต / ย้ายเครื่อง** (A6 — ต้องเขียนบนเพจขาย)

- ย้ายเครื่องเมื่อเครื่องเก่าเลิกใช้
- โควตารอบแรก: **2 ครั้งต่อใบต่อปี**
- เฟสแรกทำมือ (ออกคีย์ใหม่ให้รหัสเครื่องใหม่)
- สำรองข้อมูลไม่รวม `machine_id` / `license.json` — คงตาม [BACKUP.md](BACKUP.md)

## เฟสงาน

ทำตามลำดับ อย่าข้ามเฟส 1 ถ้าจะให้คนดาวน์โหลดเองแล้วเข้าใจโหมดทดลอง

### เฟส 1 — ล็อกโหมดทดลองในแอป (ต้องทำก่อนขาย)

ปิดช่องที่คนเข้าใจว่าโปรแกรมพัง หรือใช้ของจริงโดยไม่จ่าย

**1.1 แพ็กฟอร์มทดลอง (A3 / CP5 บางส่วน)**

- ขยาย allowlist จากชื่อเดียว (`demo-form.pdf`) เป็นชุดไฟล์ทางการ + hash
- ตัวอย่างไทย: ใบลา / ใบเบิก ตามที่มีบนเว็บแล้วได้
- ตัวอย่างสากล: อย่างน้อย 1 ใบภาษาอังกฤษ (leave / request)
- ตรวจแบบเดียวกับ `is_canonical_demo_pdf()` — กันเปลี่ยนชื่อไฟล์แล้วใช้เอกสารอื่น
- จุดแก้หลัก: `license_core.py` (`can_fill_document`), โฟลเดอร์ `demo/`, seed ตอนเปิดครั้งแรก

**1.2 ล็อกโหมดฟรี (A4)**

ไม่มีไลเซนต์แล้ว:

- `POST /api/upload` คืน 402 + ข้อความชัด
- เปิดเอกสารจากคลังที่ไม่ใช่ไฟล์ในแพ็กทดลอง ไม่ได้
- UI ซ่อน/ปิดปุ่มอัปโหลดและปุ่มคลัง (B2)

จุดแก้หลัก: `app.py`, `frontend/src/docs.ts`, `frontend/src/license.ts`, `locales/th.json`, `locales/en.json`

**1.3 ข้อความทดลองชัด (B2)**

- แถบไลเซนต์บอกว่าทดลองได้เฉพาะฟอร์มตัวอย่าง
- ปุ่มคัดลอกรหัสเครื่อง (ลดส่งรหัสผิด)
- ลิงก์ไปหน้าซื้อ / Activate (ใส่ได้หลังมี URL จริง)

**ผ่านเมื่อ**

- ไม่มีคีย์: ใช้ฟอร์มตัวอย่างได้ครบ และอัปโหลด PDF นอกไม่ได้
- มีคีย์: อัปโหลดและคลังใช้ได้ตามเดิม
- เปลี่ยนเนื้อไฟล์ตัวอย่างแล้วสร้าง PDF ไม่ได้

### เฟส 2 — นโยบาย + หน้าเว็บดาวน์โหลด (ทำแล้วใน `website/` + docs/SUPPORT.md)

ยังไม่ต้องมีร้านอัตโนมัติ ใช้ได้กับโรงเรียนไทยและออเดอร์ต่างประเทศจำนวนน้อย

**2.1 นโยบายซัพพอร์ต (A6)**

เขียนสั้นในคู่มือ/เพจ:

- อายุคีย์ไทยตามแถวที่ซื้อ (1 / 3 / 5 / 10 ปี) / ต่างประเทศ: จ่ายครั้งเดียว อัปเดตและใช้ได้ถึงวันหมดอายุบนแถบไลเซนต์
- ย้ายเครื่อง 2 ครั้ง/ปี
- ช่องทางออกคีย์ (อีเมล ชั่วคราว → หน้า Activate เฟส 4)

**2.2 เว็บ `website/`**

- หน้าแรก: ปุ่มดาวน์โหลด Setup (ชุดเดียว) + ทดลองบนเว็บที่มีอยู่
- หน้า Pricing: ตารางรายเครื่อง + ส่วนลดปริมาณ + ราคาภูมิภาค
- หน้า Pricing อังกฤษ: Personal US$49 + แถวทีม/องค์กร ไม่ปนตารางบาท
- คู่มือสั้น: ติดตั้ง → ทดลอง → คัดลอกรหัสเครื่อง → ได้คีย์ → วางในแอป

**2.3 ออกคีย์มือ (ช่องทางชั่วคราว)**

คง `scripts/gen_license.py`  
อีเมลตอบรับต้องมีเทมเพลต: ขอรหัส 16 ตัว, ส่งคีย์กลับ, สอนวางในแถบไลเซนต์  
บนเว็บอย่าสัญญา instant license จนกว่าเฟส 4 จะเสร็จ

**ผ่านเมื่อ**

- คนโหลด Setup จากเว็บแล้วทดลองได้โดยไม่ถามว่าตัวไหนคือตัวจริง
- ผู้ขายออกคีย์จากรหัสเครื่องได้ทั้งไทย (`--term` ตามแถวที่จ่าย) และต่างประเทศ (`--term 10` โดยไม่โฆษณา 10 ปี)

### เฟส 3 — หน้า Activate ให้ลูกค้าผูกเครื่องเอง

เป้าขั้นต่ำก่อนขายต่างประเทศเป็นช่องทางหลัก

```text
จ่ายเงิน (หรือได้สิทธิ์จากผู้ขาย)
    → ลิงก์ Activate
        → วาง Machine ID
            → ได้คีย์ทันที
                → วางในแอป ใช้ออฟไลน์ต่อ
```

กติกา:

- จ่าย/ออกสิทธิ์ได้ก่อนติดตั้ง ไม่ต้องมีรหัสเครื่องตอนcheckout
- 1 ออเดอร์ = N ที่นั่ง ผูกทีละเครื่องจนครบ
- Private key อยู่เฉพาะเซิร์ฟเวอร์ผู้ขาย ไม่ลง Setup
- ตรวจออนไลน์เฉพาะตอนออกคีย์
- มี log: ออเดอร์, machine_id, วันหมดอายุ — **ห้าม log คีย์เต็ม**
- ย้ายเครื่อง: เพจ “Replace this computer” นับโควตา ไม่ให้อีเมลหาผู้ขายทุกครั้งระยะยาว

อย่ารวมระบบนีเข้าแอปลูกค้าแบบให้แอปถือ private key

### เฟส 4 — ชำระเงิน (หลังเฟส 3)

- ไทย: โอน/พร้อมเพย์ ตามช่องทางที่มี + ออกสิทธิ์ในระบบ Activate
- ต่างประเทศ: Paddle / Lemon Squeezy / Stripe แล้วโยง webhook เข้าโควตาที่นั่ง
- Checkout รอบแรกขาย **1 ที่นั่ง 1 อายุ** ให้จบ (ไทยให้เลือก 1 / 3 / 5 / 10 ปี)
- หลายเครื่อง: ปุ่มจำนวน หรือฟอร์ม “Buying for a team?” จนกว่าร้านปริมาณจะคุ้มสร้าง
- บัญชีอีเมลถือหลายที่นั่งได้ — ไม่ล็อก 1 อีเมล = 1 เครื่อง และไม่แถมเครื่องที่สองในราคาใบเดียว

อย่ารอร้านปริมาณครบก่อนเปิดขายบุคคล

## โฮสต์เว็บ / อัปเดต / คีย์

เว็บและตัวติดตั้งอยู่ที่ **formdd.xambrain.com** (โฟลเดอร์ `/var/www/formdd`) คู่กับ Shed บน VPS เดียวกันผ่าน Caddy ไซต์แยก

- ไฟล์ที่ลูกค้าโหลด: `FormDD-Setup-0.3.0.exe` (ไม่ทับรุ่นเก่า) · `latest.json` ชี้รุ่นใหม่ได้อย่างเดียว
- GitHub Release สร้าง**ทุกครั้ง**เป็นสำเนา (`FormDD-Setup-x.y.z.exe` + `SHA256SUMS.txt`) — ไม่ใช่โฮสต์หลัก
- `/var/www/formdd` มีได้แค่ HTML/CSS/JS/installer/`latest.json`  
  **ห้าม**วาง private key, `gen_license.py`, `.env`, ฐานข้อมูลลูกค้า
- เฟส 3 Activate ออนไลน์: แยก `api.formdd.xambrain.com` (หรือ `/api` ผ่าน reverse proxy) — คีย์อยู่ใน secret ของ backend เท่านั้น

รายละเอียด: [UPDATE.md](UPDATE.md) · ตัวอย่าง Caddy: `website/Caddyfile.formdd`

## ความเสี่ยงที่ต้องรับ

- `machine_id` เป็นไฟล์ UUID ใน AppData ไม่ใช่ซีเรียลฮาร์ดแวร์ — คนคัดลอกโฟลเดอร์ data ได้ เฟสแรกใช้กติกา + ย้ายเครื่องแบบมีโควตา ไม่ทำ TPM ในรอบนี้
- เฟส 3 ทำให้ private key อยู่บน VPS — ต้องล็อกให้เรียกออกคีย์ได้เฉพาะออเดอร์ที่จ่ายแล้ว
- ราคาไทยถูกกว่าหน้าอังกฤษมาก — แยกสโตร์ **ห้ามบอกราคาบาทบนหน้าอังกฤษ**
