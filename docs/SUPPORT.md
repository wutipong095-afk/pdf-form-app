## โมเดล

Setup **ชุดเดียว** ทั้งทดลองและตัวจริง  
ไม่มีคีย์: ใช้ได้เฉพาะฟอร์มตัวอย่างทางการ  
มีคีย์: ใช้ PDF ของโรงเรียนได้ ไม่ต้องติดตั้งใหม่

## ราคา (ใส่เพจขาย ไม่ใส่ในแอป)

| ช่องทาง | ราคา | อายุคีย์ |
|---------|------|----------|
| ไทย | ~490 บาท / เครื่อง | ~5 ปี |
| ต่างประเทศ | US$69 / เครื่อง (PPP US$49) | ~10 ปี |

ขายรายเครื่อง องค์กรซื้อหลายเครื่องได้ส่วนลดปริมาณ  
หน้าเว็บ: [website/pricing.html](../website/pricing.html) · [website/pricing.en.html](../website/pricing.en.html)

## ย้ายเครื่อง

- ย้ายได้เมื่อเครื่องเก่าเลิกใช้
- โควตา **2 ครั้งต่อใบต่อปี**
- เครื่องใหม่ได้รหัสเครื่องใหม่ — สำรองข้อมูลไม่รวม `machine_id` / `license.json` ดู [BACKUP.md](BACKUP.md)
- เฟสนี้ผู้ขายออกคีย์ใหม่ให้มือ

## ช่องทางออกคีย์ (ชั่วคราว)

ลูกค้าส่งรหัสเครื่อง 16 ตัวมาที่ **formdd@xambrain.com**  
ผู้ขายรัน `python scripts/gen_license.py <รหัส>`  
- ไทย: `--days 1825`
- ต่างประเทศ: `--days 3650`

อย่าสัญญาออกคีย์ทันทีบนเว็บจนกว่าจะมีหน้า Activate

## สิ่งที่ซัพพอร์ต

- ติดตั้ง / เปิดใช้คีย์ / ย้ายเครื่องตามโควตา
- ฟอร์มตัวอย่างและคู่มือสั้น
- แจ้งอัปเดต Setup เมื่อมี `latest.json`

ไม่ซัพพอร์ต: คิดเงินรายพิมพ์, site license, สมัครรายเดือน, โฮสต์ไฟล์ PDF ของลูกค้า
