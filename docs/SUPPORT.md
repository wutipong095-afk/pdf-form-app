## ช่องทางออกคีย์ (ชั่วคราว)

ลูกค้าชำระเงินก่อน (Thai QR / พร้อมเพย์ ชื่อร้าน แชมเบรน — อยู่บนหน้า
[pricing.html](../website/pricing.html)) แล้วส่งสลิปพร้อมรหัสเครื่อง 16 ตัว
มาที่ **formdd@xambrain.com**

ผู้ขายรัน `python scripts/gen_license.py <รหัส> --term {1|3|5|10}` ตามอายุที่จ่าย  
- ไทย: `--term 1` / `3` / `5` / `10`
- ต่างประเทศ: `--term 10` (ภายใน; หน้าอังกฤษบอกอัปเดตตราบที่คีย์ยังใช้ได้ วันหมดอายุอยู่บนแถบไลเซนต์)
- ย้ายเครื่องโดยยกอายุที่เหลือ: `--days N` (N = จำนวนวันที่เหลือของคีย์เดิม; วันหมดอายุ UTC ใช้ `0`) — อย่าใช้ `--term` ในเคสย้ายเครื่อง ไม่งั้นได้อายุเต็มแถวโดยไม่ตั้งใจ
- สคริปต์ไม่มีค่าเริ่มต้น 5 ปี — ทุกครั้งต้องส่ง `--term` หรือ `--days` อย่างใดอย่างหนึ่ง

ออกคีย์แล้ว **จดลงทะเบียนทุกใบ** ตาม [LICENSE_REGISTRY.md](LICENSE_REGISTRY.md)
ไม่งั้นบังคับโควตาย้ายเครื่องด้านบนไม่ได้

โรงเรียนหรือหน่วยงานที่ซื้อด้วยงบต้องได้ใบเสนอราคาก่อน — [QUOTATION.md](QUOTATION.md)

อย่าสัญญาออกคีย์ทันทีบนเว็บจนกว่าจะมีหน้า Activate

## สิ่งที่ซัพพอร์ต

- ติดตั้ง / เปิดใช้คีย์ / ย้ายเครื่องตามโควตา
- ฟอร์มตัวอย่างและคู่มือสั้น
- แจ้งอัปเดต Setup เมื่อมี `latest.json`

ไม่ซัพพอร์ต: คิดเงินรายพิมพ์, site license, สมัครรายเดือน, โฮสต์ไฟล์ PDF ของลูกค้า
