# การใช้งาน FormDD

## กรอกเอกสาร

1. หน้า **แบบฟอร์ม** แสดงแม่แบบที่ใช้ได้ตามไลเซนต์ ค้นหาชื่อแล้วกด **ใช้แบบฟอร์มนี้** เพื่อเริ่มใบใหม่โดยไม่คัดลอกค่าของใบเดิม
2. กรอกข้อมูลในช่องทางซ้าย เลือกข้อมูลที่ใช้ซ้ำได้ถ้ามีสมุดข้อมูลแล้ว หรือเปิด **ช่วยกรอกทีละข้อ** ตามต้องการ ระบบบันทึกใบงานอัตโนมัติ
3. กด **ตรวจเอกสาร** เพื่อดูภาพจากตัวเรนเดอร์เดียวกับ PDF ที่จะสร้าง คำเตือนกดกลับไปแก้ช่องที่เกี่ยวข้องได้
4. กด **สร้าง PDF** แล้วเปิดไฟล์หรือโฟลเดอร์ผลลัพธ์ ใบงานยังเปิดแก้ต่อใน **งานของฉัน** ได้

ช่องเดิมที่ไม่ได้กำหนดว่าบังคับยังเว้นว่างได้ ระบบไม่เปลี่ยนกฎของแม่แบบเก่าเอง ข้อความล้นเป็นการประมาณจากฟอนต์และความกว้างช่อง จึงต้องตรวจภาพเอกสารจริงด้วย ระบบไม่ตัดหรือย่อข้อความตามคำเตือนโดยอัตโนมัติ

## เตรียมแบบฟอร์ม

1. เปิด **เตรียมแบบฟอร์ม** เพิ่มหรือเลือก PDF แล้วตั้งชื่อแบบฟอร์ม
2. คลิกบนเอกสารเพื่อกำหนดช่องกรอก เลือกช่องเพื่อแก้ชื่อ ตำแหน่ง ขนาดตัวอักษร ความกว้าง ชนิดข้อมูล หรือกำหนดให้จำเป็นต้องกรอก
3. เลือก **ทดลองกรอก** และตรวจภาพตัวอย่างก่อนบันทึกแบบฟอร์มพร้อมใช้ ค่าทดลองไม่ถูกบันทึกในแม่แบบ
4. กลับหน้า **แบบฟอร์ม** เพื่อเริ่มใบงานใหม่

ชนิดข้อมูลที่รองรับคือข้อความ ตัวเลข และวันที่ วันที่ใหม่ใช้รูปแบบ YYYY-MM-DD ช่องจำเป็นและชนิดข้อมูลถูกตรวจตอนสร้าง PDF แต่ใบงานที่กรอกไม่ครบยังบันทึกเป็นฉบับร่างได้ คุณสมบัติเหล่านี้ติดไปกับใบงานและไฟล์ .formdd ที่ส่งออก

โหมดทดลองยังจำกัดแบบฟอร์มตามนโยบายไลเซนต์เดิม แม่แบบชื่อใหม่อาจไม่ปรากฏในรายการจนกว่าจะเปิดใช้ไลเซนต์

## ตั้งค่า

ไลเซนต์ ภาษา สมุดข้อมูล สำรอง/กู้คืนข้อมูล และที่เก็บงาน อยู่ใน **ตั้งค่า** การบันทึกแม่แบบกับการบันทึกใบงานเป็นคนละอย่าง: แม่แบบเก็บตำแหน่งและกฎ ส่วนใบงานเก็บข้อมูลที่กรอก

## การตรวจสอบ

- ทดสอบว่าภาพจาก `/api/fill-preview` ตรงกับภาพเรนเดอร์ของไฟล์ PDF ที่สร้าง และการเปิดดูตัวอย่างไม่สร้างไฟล์ในโฟลเดอร์ผลลัพธ์
- ทดสอบกฎช่องบังคับ ชนิดข้อมูล หน้าเอกสารที่หายไป และการประมาณข้อความล้น
- ทดสอบว่าข้อมูลและกฎช่องยังครบหลังส่งออก/นำเข้า .formdd
- ทดสอบการเลือกแม่แบบและการหยุดเปลี่ยนหน้าหากบันทึกไม่สำเร็จ
- ตรวจหน้าจอจริงที่ขนาดเดสก์ท็อปและความกว้าง 390px

สไตล์ต้นฉบับอยู่ใน `frontend/public/css/workflow.css` การบิวด์จะคัดลอกไป `static/css/workflow.css` พร้อมบันเดิลหน้าจอ
