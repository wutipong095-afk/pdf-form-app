# ทะเบียนคีย์ไลเซนต์ (ผู้ขาย)

คู่กับ [SUPPORT.md](SUPPORT.md) · [LICENSE_EMAIL.md](LICENSE_EMAIL.md) · [SALES_LICENSE_PLAN.md](SALES_LICENSE_PLAN.md)

## ทำไมต้องมี

[SUPPORT.md](SUPPORT.md) ประกาศกับลูกค้าว่า **ย้ายเครื่องได้ 2 ครั้งต่อใบต่อปี**
กติกานี้บังคับไม่ได้เลยถ้าไม่จดว่าใบไหนใช้โควตาไปแล้วกี่ครั้ง — คีย์ผูก `machine_id`
และตัวโปรแกรมทำงานออฟไลน์ ไม่มีเซิร์ฟเวอร์ไหนรู้ว่าใครถือคีย์อะไรอยู่
**ทะเบียนนี้คือบันทึกชุดเดียวที่มี**

## ห้าม commit ไฟล์จริง

เรปนี้เป็น **สาธารณะ** ทะเบียนมีชื่อหน่วยงาน อีเมล และรหัสเครื่องของลูกค้า
ไฟล์จริงชื่อ `license-registry.csv` ถูกใส่ใน `.gitignore` แล้ว — เก็บไว้นอกเรป
เช่นโฟลเดอร์เอกสารส่วนตัวหรือ Google Sheets ส่วนตัว

ในเรปมีแค่ [license-registry.example.csv](license-registry.example.csv) ที่เป็นหัวตารางกับแถวตัวอย่างปลอม

## คอลัมน์

| คอลัมน์ | ความหมาย |
|---|---|
| `issued_at` | วันที่ออกคีย์ `YYYY-MM-DD` |
| `product` | ผลิตภัณฑ์ — ตอนนี้มีแต่ `FormDD` เผื่อไว้ให้แบรนด์อื่นใต้ xambrain |
| `org` | ชื่อโรงเรียน / หน่วยงาน / ชื่อผู้ซื้อรายบุคคล |
| `email` | อีเมลที่ติดต่อกลับ — ใช้ยืนยันตัวตอนขอย้ายเครื่อง |
| `machine_id` | รหัสเครื่อง 16 hex ที่คีย์ผูกอยู่ |
| `days` | อายุที่ออกให้ — ไทย `365` / `1095` / `1825` / `3650` ตามแถวที่จ่าย ต่างประเทศ `3650` |
| `amount_thb` | ยอดที่รับจริง (หลังหักส่วนลดปริมาณแล้ว) |
| `paid_ref` | อ้างอิงการชำระเงิน เช่น เลขอ้างอิงสลิป หรือเลขใบเสนอราคา |
| `transfer_no` | ใบนี้เป็นการย้ายเครื่องครั้งที่เท่าไรของปีนั้น — `0` คือคีย์ใบแรก |
| `replaces` | `machine_id` เดิมที่ใบนี้มาแทน (ว่างถ้าเป็นใบแรก) |
| `note` | อย่างอื่น เช่น เลขที่ใบเสนอราคา หรือเหตุผลที่ย้าย |

## ขั้นตอนตอนออกคีย์

1. ตรวจว่าได้รับเงินแล้วจริง
2. ออกคีย์
   ```
   python scripts/gen_license.py <machine_id> --days {365|1095|1825|3650}
   ```
3. ส่งคีย์ด้วยเทมเพลตใน [LICENSE_EMAIL.md](LICENSE_EMAIL.md)
4. **จดลงทะเบียนทันที** อย่าผัดไว้ — คีย์ที่ออกแล้วแต่ไม่ได้จด เท่ากับไม่มีอยู่จริง

## ขั้นตอนตอนลูกค้าขอย้ายเครื่อง

นโยบายคือ **2 ครั้งต่อใบต่อปี** ไม่ใช่ต่ออีเมล

1. ยืนยันตัวด้วย `email` ให้ตรงผู้ถือใบนั้น
2. หาใบจาก `machine_id` เดิม แล้วไล่สาย `replaces` กลับไปใบแรกของที่นั่งนี้ — อย่านับใบอื่นที่ใช้อีเมลเดียวกัน
3. นับแถวย้ายของสายนี้ที่ `issued_at` อยู่ใน **ปีปฏิทินนี้** (`transfer_no` > 0) — ถ้าครบ 2 ครั้งแล้วให้ปฏิเสธ
4. ออกคีย์ใหม่ด้วยรหัสเครื่องใหม่ อายุเท่าที่เหลือหรือเต็มตามที่ตกลง
5. จดแถวใหม่ ใส่ `replaces` เป็น `machine_id` เดิม และ `transfer_no` เป็นลำดับของปีนี้ (เริ่มที่ 1 ใหม่ทุกปีปฏิทิน) — **ไม่แก้แถวเดิม** ทะเบียนเป็นบันทึกต่อเนื่อง ไม่ใช่สถานะปัจจุบัน
