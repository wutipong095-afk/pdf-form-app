ติดตั้งบน Windows

ดาวน์โหลดและติดตั้ง FormDD

ระหว่างติดตั้งจะเจอจอเตือนสีน้ำเงินของ Windows ว่า “ผู้เผยแพร่ที่ไม่รู้จัก” — เป็นเรื่องปกติของโปรแกรมจากผู้พัฒนารายเล็ก ไม่ใช่ไวรัส กดผ่านได้ตามขั้นตอนด้านล่าง

ดาวน์โหลด Setup (Windows) ดูราคา
① ดาวน์โหลด Setup

กดปุ่ม “ดาวน์โหลด” ด้านบนเท่านั้น ไฟล์อยู่บน GitHub Releases ที่ปุ่มชี้ให้ — ได้ชื่อ FormDD-Setup-x.y.z.exe อย่าโหลดจากเว็บอื่น

② เปิดไฟล์ที่โหลดมา

ดับเบิลคลิกไฟล์ ถ้าเบราว์เซอร์เตือน “ไฟล์นี้ดาวน์โหลดไม่บ่อย” ให้เลือก เก็บไว้ (Keep)

③ ผ่านจอ “Windows ปกป้องพีซีของคุณ”

นี่คือจอ SmartScreen สีน้ำเงิน ไม่ใช่คำขอสิทธิ์ผู้ดูแล กด ข้อมูลเพิ่มเติม (More info) แล้วกด เรียกใช้อยู่ดี (Run anyway) — ปุ่มจะขึ้นหลังกดข้อมูลเพิ่มเติมเท่านั้น

④ ทำตามตัวติดตั้งจนเสร็จ

กด ถัดไป (Next) ไปเรื่อย ๆ ตัวติดตั้งลงในโฟลเดอร์ของผู้ใช้ ไม่ต้องสิทธิ์ผู้ดูแล และไม่ควร “เรียกใช้ในฐานะผู้ดูแล”

⑤ เปิดจากไอคอน FormDD

เสร็จแล้วเปิดจากไอคอนบนเดสก์ท็อป ทดลองใช้ฟอร์มตัวอย่างได้ทันที ยังไม่ต้องมีคีย์

ทำไม Windows ขึ้นเตือน “ผู้เผยแพร่ที่ไม่รู้จัก”?

Windows จะยกป้ายเตือนกับโปรแกรมทุกตัวที่ยังไม่มี ใบรับรองดิจิทัล (code signing) ที่มันรู้จัก FormDD เป็นโปรแกรมจากทีมเล็ก กำลังอยู่ระหว่างจัดทำใบรับรองนั้น — คำเตือนจึงขึ้นไว้ก่อน ไม่ได้แปลว่าไฟล์มีไวรัสหรือถูกแก้

อยากมั่นใจก่อนติดตั้ง ตรวจได้ 3 ทาง: (1) ดาวน์โหลดจากลิงก์ทางการเท่านั้น (2) เทียบค่า SHA256 ของไฟล์ (ดูด้านล่าง) (3) สแกนด้วย Windows Defender หรืออัปโหลดเช็คที่ virustotal.com

สำหรับฝ่าย IT — ตรวจสอบไฟล์ด้วย SHA256

ทุกรุ่นแนบไฟล์ SHA256SUMS.txt ไว้ในหน้า Release เปิด PowerShell แล้วรัน:

Get-FileHash .\FormDD-Setup-x.y.z.exe -Algorithm SHA256

นำค่าที่ได้ไปเทียบกับบรรทัดในไฟล์ SHA256SUMS.txt ถ้าตรงกัน แปลว่าไฟล์ครบถ้วนไม่ถูกแก้ระหว่างทาง

Defender ลบไฟล์ทิ้ง?

เปิด Windows Security → Protection history → เลือกไฟล์ FormDD แล้วกด Allow / Restore

ติดตั้งไม่ขึ้น?

ตัวติดตั้งไม่ต้องสิทธิ์ผู้ดูแล ถ้าไฟล์หาย ให้ดูข้อ Defender ด้านบน แล้วดาวน์โหลดใหม่จากปุ่มบนหน้านี้ อย่ารัน Setup ในฐานะผู้ดูแล — จะลงคนละโฟลเดอร์กับงานที่กรอก

ถอนการติดตั้ง

Settings → Apps → ค้นหา “FormDD” → Uninstall — ข้อมูลงานของคุณจะยังอยู่จนกว่าจะลบเอง
